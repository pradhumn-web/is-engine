TWO USER PERSPECTIVES

Designed for both sides of procurement.

B

Buyer / Officer

TENDER AUTHORITY WORKFLOW
  • Review the recommended standard and likely evidence gaps.
  • Check the cited revision and inspect possible obsolete-code flags.
  • Copy draft language for SCC, inspection/testing, and ITB sections.
  • Review bidder qualification documents and audit findings.

Use this view as a drafting and screening aid. Confirm every clause and applicable Quality Control Order through current official sources.

C

Bidder / Contractor

OFFER PREPARATION WORKFLOW
  • Review the indicative bid-readiness score and verdict.
  • Use the clause matrix to locate missing or deviating requirements.
  • Follow action notes and the Envelope A evidence checklist.
  • Review conditional equivalence suggestions before proposing alternatives.

The score is prototype logic, not a bid-acceptance decision or a guarantee of tender responsiveness.

READING YOUR RESULTS

What each signal means.

Match relevance and clause conformance are different signals. Review both before drawing conclusions.

Match percentageRelative retrieval relevance for this query—not probability of legal compliance or certification.
AlignedText appears to cover the clause based on the prototype’s matching rules; verify supporting evidence.
Partial / MissingSome coverage may be absent or unclear. Check the full clause and tender-specific evidence.
DeviatedAn explicit value may exceed a demo reference threshold. Confirm units, scope, edition, and applicable test method.
Important: A high match or readiness score is not a compliance certificate, legal opinion, engineering approval, or award recommendation. Treat every result as a prompt for qualified human review.

FOR YOUR SIH TEAM

Run it locally in two terminals.

Requires Python 3.10+ and Node.js 20+. From the extracted bis-engine project folder:

Start the API, then the workbench.

TERMINAL 1 / BACKEND
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=. uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
TERMINAL 2 / FRONTEND
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
Open http://localhost:5173 · API health: http://localhost:8000/health · Stop each server with Ctrl+C.
